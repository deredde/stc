# LassoSelect

Si trascina sul fondo per disegnare un rettangolo: tutto quello che tocca si seleziona. Con le scorciatoie di sempre, e una barra che dice quanti e quanto pesano.

**Cosa passi:** `items`, `height` (di serie 360).

**Quando usarlo**
- Griglie di file, foto o schede dove si lavora su molti elementi insieme.

**Quando no**
- Liste di righe di testo: bastano le caselle di spunta.
- Telefono come unico modo: lì si tiene premuto per entrare in selezione e si tocca.

**Regole**
- Il lazo parte solo dal fondo, mai sopra un elemento.
- Maiusc o Ctrl aggiungono alla selezione che c'è; senza, la sostituiscono.
- Maiusc+clic seleziona l'intervallo, Ctrl+clic uno alla volta, Ctrl+A tutto, Esc niente.
- Frecce per muoversi nella griglia, Spazio per scegliere.
- La barra dice quanti elementi e quanto pesano, con le azioni sempre lì.
- Su schermi touch il segno di spunta è sempre visibile.

**Stati coperti:** Nessuna selezione · Lazo in corso · Selezione multipla · Hover · Focus · Nome lungo.
