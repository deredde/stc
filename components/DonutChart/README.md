# DonutChart

Ciambella per le parti di un totale: al massimo 5 parti dai token `viz-1` … `viz-5`, ordinate dalla più grande. Totale al centro; la legenda è anche la tabella dei valori.

**Cosa passi:** `data` (`{label, value, color}`), `format`, `totalLabel`, `size`, `label`, `legend`.

**Regole**
- Oltre cinque parti, l'ultima è «Altro».
- Al passaggio su una parte il centro mostra quella.
