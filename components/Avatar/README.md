# Avatar

Le iniziali (o la foto) di una persona in un cerchio.

**Cosa passi:** `name` (le iniziali si ricavano da qui), `initials`, `src`, `size` (24 · 32 di serie · 36 · 40 · 48 · 56 · 80), `dot` (pallino di stato). `AvatarAdd` è il cerchio tratteggiato «Aggiungi foto».

**Regole:** 32 nelle tabelle, 36 nelle liste e nelle ricerche, 56 nella testata della scheda, 80 nel modulo. Il pallino solo se lo stato cambia spesso (in linea, dentro adesso).
