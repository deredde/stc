# Count

Contatore: un numero in una pastiglia, solo su ciò che aspetta un'azione.

**Cosa passi:** `value`, `tone` (`muted` di serie nei tab · `primary` nei filtri · `danger` in barra laterale · `accent`), `max` (99, poi «99+»), `label` per lo screen reader.

**Regole:** niente contatori su ciò che è solo informazione. Zero non si mostra.
