# MegaMenu

Un menu largo per i siti con tante pagine: colonne di link e una novità in evidenza. Su telefono diventa una fisarmonica.

**Cosa passi:** `menus`, `brand` (di serie Esempio), `defaultOpen`.

**Quando usarlo**
- Siti pubblici con più di 12 pagine da raggiungere dall'intestazione.

**Quando no**
- Dentro l'app.
- Siti con poche pagine: basta l'intestazione semplice.

**Regole**
- Al massimo tre colonne di link e una novità; sei link per colonna.
- Si apre dopo una breve pausa del mouse, si chiude con Esc o fuori.
- Si apre anche con Invio e con la freccia giù; il focus resta dentro.
- Sotto 860 px: menu a scomparsa con sezioni che si aprono.

**Stati coperti:** Chiuso · Aperto · Focus · Telefono · Scuro.
