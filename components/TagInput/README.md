# TagInput

Etichette libere: si scrive e si preme Invio (o la virgola). Backspace su un campo vuoto toglie l'ultima.

**Cosa passi:** `value` / `defaultValue` (lista), `onChange`, `placeholder`, `lowercase` (di serie sì), `label`.

**Regole**
- Le etichette doppie non entrano.
- Per scegliere da una lista chiusa usa `MultiSelect`.
