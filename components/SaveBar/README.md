# SaveBar

Barra scura «non ancora creato», in cima alla pagina finché il nuovo elemento non è salvato.

**Cosa passi:** `message`, `icon`, `cancelLabel`, `onCancel`, `confirmLabel`, `onConfirm`, `loading`.

**Regole**
- Solo dove si crea qualcosa di nuovo. Nelle impostazioni non serve: lì si salva da solo.
- Il bottone dice cosa crea: «Crea il cliente».
