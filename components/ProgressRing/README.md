# ProgressRing

Anello di avanzamento: primario su `surface-active`, estremità tonde, valore al centro in mono. Piccolo (40) accanto a un testo che dice cosa sta succedendo.

**Cosa passi:** `value` (0–100), `size` (120), `stroke`, `label`, `showValue`.

**Regole**
- Per obiettivi e caricamenti lunghi. Per i limiti del piano usa `UsageMeter`.
