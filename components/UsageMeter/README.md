# UsageMeter

Consumo di un limite del piano (utenti, sedi, SMS, spazio): barra primaria, dall'80 % arancio con la frase che dice cosa succede, al 100 % rossa.

**Cosa passi:** `label`, `used`, `max`, `unit`, `note`, `format`.

**Regole**
- La frase a 80 % e 100 % è obbligatoria: dice cosa succede e cosa fare.
- In una card del piano, con il link «Cambia piano».
