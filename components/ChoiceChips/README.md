# ChoiceChips

Chip di scelta, una sola o più di una: bordo e testo primari con la spunta, non un fondo colorato.

**Cosa passi:** `options` (`{value, label, icon, disabled}`), `value` / `defaultValue`, `onChange`, `multiple`, `label`.

**Regole**
- Per scelte rapide sopra una lista o in un modulo breve.
- Per i filtri applicati resta `Chip` con `onRemove`.
