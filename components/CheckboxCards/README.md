# CheckboxCards

Scelta multipla fatta di card, per aggiungere moduli o servizi. Sotto, il totale che cambia mentre scegli.

**Cosa passi:** `options` (come `RadioCards`), `value` / `defaultValue` (lista), `onChange`, `label`.

**Regole**
- La casella sta a sinistra, l'icona (facoltativa) subito dopo.
- Il totale sotto è responsabilità della pagina: una riga, in mono a destra.
