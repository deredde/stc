# Segmented

Scelta tra 2–4 viste o modi: Oggi · Settimana · Mese.

**Cosa passi:** `options` (stringhe o `{ value, label, icon }`), `value` / `defaultValue`, `onChange`, `full` (riempie la larghezza), `size` (`card` 30 · `form` 34), `label`.

**Regole:** cambia come si guarda, non filtra i dati (per quello c'è `FilterMenu`). Frecce destra e sinistra per spostarsi.
