# Timeline

Storico e attività di una scheda: icona per tipo nella tessera del tono giusto, chi in grassetto, ora e luogo in mono.

**Cosa passi:** `groups` (`{label, items}`) oppure `items` senza gruppi; ogni voce `{id, icon, tone, text, meta, note}`.

**Regole**
- Le eccezioni (un ingresso forzato, un rimborso) portano il motivo in `note`.
- Il più recente in alto, gruppi per giorno.
