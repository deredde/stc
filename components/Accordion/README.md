# Accordion

Fisarmonica: ogni voce ha un titolo e sotto il riassunto di cosa c'è dentro, che si legge anche da chiusa.

**Cosa passi:** `items` (`{id, title, summary, content}`), `value` / `defaultValue` (le voci aperte), `onChange`, `multiple` (di serie più voci aperte insieme).

**Regole**
- Per impostazioni lunghe e domande frequenti. Per i dati di una scheda usa le card.
- Il riassunto è il valore attuale, non una spiegazione.
