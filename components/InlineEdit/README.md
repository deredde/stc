# InlineEdit

Testo che si modifica sul posto: la matita compare al passaggio, Invio salva, Esc annulla.

**Cosa passi:** `value` / `defaultValue`, `onSave(testo)`, `label` (cosa si sta modificando), `size` (`sm` · `md` · `lg`), `placeholder`.

**Regole**
- Per nomi e titoli brevi. Più di un campo: apri un `Drawer`.
- Dopo il salvataggio, il toast «Salvato».
