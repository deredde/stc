# ProgressSteps

Un lavoro lungo in più fasi: fatto con la spunta, in corso con la rotella, il resto in attesa.

**Cosa passi:** `steps` (array di testi, anche con numeri: «Controllo 1.284 righe»), `current` (indice del passo in corso; uguale alla lunghezza quando è tutto fatto).

**Regole:** frasi al gerundio o in prima persona, brevi. Per un lavoro di una sola fase usa `ProgressBar`.
