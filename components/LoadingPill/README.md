# LoadingPill

Pillola di vetro con la rotella e una frase breve. `LoadMore` è la stessa pillola in fondo alle liste lunghe.

**Cosa passi:** `LoadingPill`: `label` o `children`. `LoadMore`: `label` («Carico altri»), `count`.

**Regole**
- Sopra uno scheletro dopo 2 s («Carico i clienti»), in fondo a una lista mentre arriva la pagina dopo, dentro la ricerca.
- Le righe già caricate restano usabili.
