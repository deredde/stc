# ColorSwatches

Scelta di un colore tra i campioni della palette, per sale, categorie, calendari.

**Cosa passi:** `options` (`{value, label, color}` dove `color` è il nome di un token, di serie `COLORI_STC`), `value` / `defaultValue`, `onChange`, `label`.

**Regole**
- Solo colori dalla palette: niente selettore libero.
- Ogni campione ha il nome per lo screen reader e al passaggio.
