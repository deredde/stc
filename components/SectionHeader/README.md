# SectionHeader

Testata di una sezione dentro la pagina: titolo con una riga di spiegazione e le azioni piccole a destra. In versione card con il contatore e il link «Tutti …».

**Cosa passi:** `title`, `description`, `actions`, `count`, `link` (`{label, onClick, href}`), `size` (`page` · `card`), `as` (il tag del titolo).

**Regole**
- `page`: titolo 20/600. `card`: 16/600.
- Le azioni sono da 32 (`size="card"`), al massimo due.
