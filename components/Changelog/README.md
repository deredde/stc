# Changelog

Le versioni in ordine, con etichette che si filtrano e le voci da leggere in evidenza.

**Cosa passi:** `entries`, `seen` (di serie 0), `loading`, `pageSize` (di serie 3).

**Quando usarlo**
- Pagina pubblica delle novità e pannello «Cosa c'è di nuovo» nell'app.

**Quando no**
- Note tecniche per sviluppatori: vanno nel registro del codice.

**Regole**
- Quattro etichette fisse: Nuovo, Meglio, Corretto, Rimosso. Colore e testo insieme.
- Una frase per voce; l'immagine solo per le novità grandi.
- Le versioni non lette hanno il segno «Da leggere».
- Tre versioni per volta, poi «Versioni precedenti».
- Un filtro senza risultati dice cosa fare e permette di tornare a tutto.

**Stati coperti:** Da leggere · Letto · Filtrato · Filtro vuoto · Carica altre · Caricamento · Fine elenco.
