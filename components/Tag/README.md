# Tag

Etichetta di categoria, squadrata (raggio 6) per non confondersi con i `Badge` tondi degli stati. Il colore è solo il pallino.

**Cosa passi:** `children`, `color` (nome di un token: `viz-1`, `info-solid`…), `onRemove`, `outline`, `size` (`md` · `lg`), `onClick`.

**Regole**
- Per classificare, non per dire lo stato.
- In tabella al massimo due, poi «+N» con `outline`.
