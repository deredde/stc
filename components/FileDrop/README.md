# FileDrop

Zona dove trascinare un file, con «Scegli file» e, su telefono, «Scatta foto».

**Cosa passi:** `title` (cosa caricare), `text` (formati e limiti), `accept`, `multiple`, `onFiles(files)`, `icon`, `camera`, `chooseLabel`. Mentre carica mostra `FileProgress` sotto.

**Regole:** il titolo nomina il documento («Documento d'identità»), non l'azione. Scrivi i formati accettati.
