# TextLink

Link d'azione nel testo e nelle card: «Apri», «Tutti gli ordini», «Azzera».

**Cosa passi:** `children`, `href` oppure `onClick`, `tone` (`default` · `muted` · `danger`).

**Regole:** 13/600 d'inchiostro, sottolineato solo al passaggio. In un avviso o in una card c'è al massimo un link. Se porta a un'azione che cambia dati, preferisci un `Button`.
