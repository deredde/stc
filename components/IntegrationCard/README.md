# IntegrationCard

Card di un'integrazione: logo, cosa fa in una frase, stato. Le card stanno in `IntegrationGrid`.

**Cosa passi:** `logo` (sigla o immagine), `name`, `description`, `connected`, `onConnect`, `onSettings`, `onDisconnect` e le etichette dei bottoni.

**Regole**
- «Collega» è secondario, mai primario.
- La frase dice cosa succede ai dati, non cosa è il servizio.
