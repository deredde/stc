# UndoHistory

Ogni modifica è un passo nella cronologia a fianco: si torna indietro con Ctrl+Z o toccando un passo, e si vede cosa si perderebbe cambiando qualcosa dal passato.

**Cosa passi:** niente, è un esempio completo da adattare.

**Quando usarlo**
- Editor dove si prova e si riprova: grafica, testi, configurazioni.

**Quando no**
- Moduli normali: basta «Annulla» sul singolo campo.
- Azioni che toccano altre persone o soldi: servono conferme, non disfa.

**Regole**
- Ctrl+Z annulla, Ctrl+Maiusc+Z ripete, anche dalla tastiera del campo.
- Scrittura e trascinamenti continui diventano un solo passo.
- I passi futuri restano barrati finché non si cambia qualcosa.
- Se si cambia dal passato, avvisa quanti passi sono stati sostituiti.
- L'avviso «Stai guardando il passato» compare quando non si è all'ultimo passo.
- Su telefono la cronologia va sotto.

**Stati coperti:** Primo passo · Ultimo passo · Nel passato · Passi sostituiti · Annulla e Ripeti disattivi · Focus.
