# RadioGroup

Scelta di una sola voce tra poche, tutte a vista.

**Cosa passi:** `options` (`value`, `label`, `description`), `value` / `defaultValue`, `onChange`, `direction` (`column` · `row`), `label`.

**Regole:** fino a 5 voci. Con descrizioni lunghe, una per riga. Per cambiare vista o modo usa `Segmented`.
