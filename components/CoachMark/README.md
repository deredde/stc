# CoachMark

Giro guidato: un fumetto scuro alla volta, con la cosa nuova illuminata.

**Cosa passi:** `children` (l'elemento da illuminare), `title`, `text`, `step`, `total`, `onSkip`, `onNext`, `skipLabel`, `nextLabel`, `open`.

**Regole**
- Al massimo 3 passi, «Salta» sempre visibile.
- Solo per cose nuove o cambiate, una volta per persona.
