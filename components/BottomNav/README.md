# BottomNav

Barra in basso del gestionale su telefono: quattro voci, quella al centro piena d'accento.

**Cosa passi:** `items` (`id`, `label`, `icon`, `dot`, `primary`), `value`, `onChange`.

**Regole:** la voce `primary` è l'azione che si fa più spesso (Nuovo ordine, Vendi). L'ultima è «Menu», che apre tutte le sezioni. Il pallino rosso su ciò che aspetta.
