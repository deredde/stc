# MentionInput

Nel commento si scrive @ per citare una persona e # per un argomento. Le persone citate ricevono l'avviso.

**Cosa passi:** `people`, `tags`, `placeholder`, `onSend`.

**Quando usarlo**
- Commenti, note interne, assegnazione di compiti in un team.

**Quando no**
- Messaggi a chi non è nel team: la menzione non arriva a nessuno.

**Regole**
- L'elenco si apre sotto il cursore e filtra mentre si scrive.
- Frecce, Invio o Tab per scegliere; Esc chiude.
- La menzione diventa un pezzo unico che si cancella tutto insieme.
- Chi è fuori ufficio lo si vede nell'elenco.
- Dopo l'invio, sotto il messaggio, chi è stato avvisato.

**Stati coperti:** Vuoto · Elenco persone · Elenco argomenti · Nessun risultato · Fuori ufficio · Inviato.
