# ImageCrop

Si trascina la foto dentro la cornice, si ingrandisce e si ruota. Le anteprime mostrano come apparirà nelle misure vere.

**Cosa passi:** `shape` (di serie circle), `ratio` (di serie 1), `hue` (di serie 210), `defaultZoom` (di serie 1.3).

**Quando usarlo**
- Foto profilo, logo, copertine dopo il caricamento.

**Quando no**
- Ritocchi veri (colori, filtri): serve un editor di immagini.

**Regole**
- La foto non lascia mai vuoti nella cornice: lo spostamento ha un limite.
- Ingrandimento da 100% a 300%; frecce per spostare, + e − per ingrandire.
- La griglia dei terzi compare solo mentre si trascina.
- Le anteprime nelle misure in cui la foto si vedrà davvero.
- «Ricomincia» riporta tutto all'inizio.

**Stati coperti:** Pronta · Trascinamento · Ingrandita · Ruotata · Salvata.
