# Skeleton

Blocchi grigi che scintillano al posto del contenuto mentre arriva.

**Cosa passi:** `width`, `height`, `radius`, `circle`. `SkeletonRow` è una riga di lista già pronta (cerchio e due righe).

**Regole:** disegna la forma vera di ciò che arriva (stesse altezze, stesse card). Niente rotelle a pagina intera. Per una pagina intera c'è `StatePage kind="loading"`.
