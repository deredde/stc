# DocumentLoader

Un foglio con una luce che lo scorre dall'alto in basso, mentre si prepara un documento.

**Cosa passi:** `title` («Preparo la fattura»), `code` (numero del documento), `detail` («PDF, 2 pagine»).

**Regole:** per PDF, fatture, report ed export. Alla fine il documento si apre o parte lo scaricamento, con un toast.
