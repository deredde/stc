# TileSelect

Tessere con icona per scegliere un tipo all'inizio di un percorso (che attività hai, che cosa vuoi creare).

**Cosa passi:** `options` (`{value, icon, title, description}`), `value` / `defaultValue`, `onChange`, `label`, `min` (larghezza minima, 150).

**Regole**
- Da 4 a 8 tessere; l'icona della scelta passa all'accento.
- L'ultima può essere «Altro · Partiamo da zero».
