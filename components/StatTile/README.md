# StatTile

Tessera KPI: un numero che conta, il suo nome e una riga di contesto.

**Cosa passi:** `title`, `value`, `note`, `icon`, `tone` (colora la tessera dell'icona), `onClick`, `loading`.

**Regole:** in fila da 3 o 4. Il numero in mono 30/500 con l'unità («€ 1.240,00»). La nota dice da dove viene o cosa significa, non ripete il titolo.
