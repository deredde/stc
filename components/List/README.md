# List

Lista di righe dentro una card: icona o avatar, titolo, una riga sotto, qualcosa a destra.

**Cosa passi:** `List` contiene `ListRow`: `title`, `meta`, `leading` o `icon`, `trailing` (badge, importo), `onClick`, `chevron`, `tone` (`danger` per «Esci»).

**Regole:** per elenchi corti, per le schede e per il telefono, dove la tabella non ci sta. Le righe si separano con una linea, senza spazio tra loro.
