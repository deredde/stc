# AuthScreen

Accesso, attivazione, password: superficie di marca, titolo e frase, il modulo su vetro.

**Cosa passi:** `name` o `logo`, `title`, `text`, `alert`, `children` (i `Field`), `action` (`label`, `onClick`, `loading`, `disabled`), `link` (`label`, `onClick`), `footer`.

**Regole:** il bottone dice cosa succede («Entra», «Imposta la password»). Gli errori si dicono in chiaro sopra i campi («Ti restano 2 tentativi»). Campi alti 48, bottone 52 pieno d'accento.
