# BrandPanel

Superficie di marca, scura nei due temi: trama leggera e un bagliore dell'accento.

**Cosa passi:** `pattern` (`dots` griglia a punti · `knurl` zigrinatura · `grain` grana · `none`), `glow` (`bottom` · `top-right` · `corners` · `none`), `radius`, `as`, `children`. `BrandGlass` è il pannello di vetro da metterci sopra.

**Regole:** per accesso, testata della barra laterale, tessera dell'app e un numero in evidenza. Mai per le card normali. Sopra la marca il testo è `on-brand`, il bottone `brand-accent` con testo `brand-ink`.
