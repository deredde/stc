# SplitButton

Bottone diviso: l'azione principale a sinistra, le varianti nel menu a destra.

**Cosa passi:** `children` (l'azione), `onClick`, `items` e `onSelect` (le voci di `Menu`), `variant` (primary), `size`, `icon`, `menuLabel`, `disabled`.

**Regole**
- Le varianti fanno la stessa cosa in un altro modo («Registra e manda la ricevuta»). Azioni diverse vanno nel menu ⋮.
