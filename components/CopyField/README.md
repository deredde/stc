# CopyField

Campo di sola lettura con il bottone «Copia», che diventa «Copiata» per un secondo e mezzo.

**Cosa passi:** `value` (cosa si copia), `display` (cosa si vede, per esempio la chiave mascherata), `icon`, `mono` (di serie sì), `copyLabel`, `copiedLabel`, `onCopy`.

**Regole**
- Per chiavi, link di prenotazione, codici da girare a qualcuno.
- Per una chiave segreta, la frase d'aiuto dice chi la può usare.
