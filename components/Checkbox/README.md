# Checkbox

Casella per scelte indipendenti; anche tre stati («alcuni scelti») in testa alle tabelle.

**Cosa passi:** `checked` / `defaultChecked`, `onChange(bool)`, `indeterminate`, `label`, `description`, `disabled`, `aria-label` se non c'è etichetta.

**Regole:** il clic sulla casella in una riga di tabella sceglie la riga e non la apre. Per accendere una regola che vale subito usa `Switch`.
