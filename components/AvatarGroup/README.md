# AvatarGroup

Avatar sovrapposti di 8 con il bordo della superficie; oltre il massimo, «+N».

**Cosa passi:** `names`, `max` (4), `size` (32), `label`.

**Regole**
- Le aziende hanno l'avatar quadrato (`className="stc-avatar--square"` su `Avatar`), le persone tondo.
- Al passaggio su «+N» si leggono i nomi nascosti.
