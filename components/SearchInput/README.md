# SearchInput

Ricerca: della pagina (44) o dentro una card (32), con la × per svuotare.

**Cosa passi:** `value`, `onChange(testo)`, `size` (`header` · `card`), `placeholder` («Cerca per nome, codice o telefono»), `shortcut` (es. «/», che porta qui il fuoco da tutta la pagina), `width`.

**Regole:** il segnaposto dice per cosa si può cercare. Esc svuota. Filtra mentre scrivi, senza bottone «Cerca».
