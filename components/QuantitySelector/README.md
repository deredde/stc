# QuantitySelector

Selettore quantità: meno, il numero, più.

**Cosa passi:** `value` / `defaultValue`, `onChange`, `min`, `max`, `step`, `label`, `disabled`.

**Regole:** per numeri piccoli che si cambiano di uno (colli, ingressi, posti). Il numero si può anche scrivere; frecce su e giù lo cambiano.
