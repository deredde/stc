# UpgradeCard

Invito al piano superiore quando tocchi un limite, mai a caso: superficie di marca, cosa sblocca, quanto costa. In versione `compact` sulle voci chiuse.

**Cosa passi:** `overline`, `title`, `text`, `features`, `primary` e `secondary` (`{label, onClick}`), `compact`, `icon`.

**Regole**
- Il titolo dice il limite toccato («Hai finito i posti per gli utenti»).
- Il prezzo sta nel bottone.
