# Tooltip

Etichetta scura che compare dopo 400 ms al passaggio o al fuoco.

**Cosa passi:** `label`, un solo figlio che riceve il mouse e il fuoco, `placement` (`top` · `right` · `bottom`), `delay`, `open` per forzarlo.

**Regole:** nomina un comando a sola icona o spiega un dato. Mai informazioni che servono per agire, mai sui telefoni come unico modo di sapere qualcosa.
