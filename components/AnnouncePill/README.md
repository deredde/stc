# AnnouncePill

La piccola pillola sopra il titolo di una pagina pubblica che porta alla novità del momento.

**Cosa passi:** `tag` (di serie Nuovo), `text`, `href` (di serie #), `variant` (di serie default), `shine` (di serie true), `loading`.

**Quando usarlo**
- Sopra il titolo della home o di una landing, per una sola novità.

**Quando no**
- Dentro l'app: lì le novità vanno nel Registro delle novità o in un Banner.
- Per offerte con scadenza: Barra promo.

**Regole**
- Una pillola per pagina, testo al massimo 60 caratteri, etichetta di una parola.
- È sempre un link, con la freccia che si sposta al passaggio.
- Il bordo che gira solo per novità recenti; spento col movimento ridotto.

**Stati coperti:** Riposo · Hover · Focus · Testo lungo · Caricamento.
