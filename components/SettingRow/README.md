# SettingRow

Una regola che si accende o si spegne, in una card: titolo, una riga di spiegazione, l'interruttore.

**Cosa passi:** `title`, `description`, `checked` / `defaultChecked`, `onChange`, `disabled`; oppure `children` al posto dell'interruttore (un `Select`, un bottone).

**Regole:** il titolo è la regola detta in positivo («Blocca gli ordini con fattura scaduta»). La spiegazione dice cosa succede quando è accesa.
