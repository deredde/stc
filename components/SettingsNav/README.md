# SettingsNav

Elenco delle sezioni delle impostazioni, a sinistra, largo 220.

**Cosa passi:** `items` (`id`, `label`, `alert`: pallino rosso per ciò che va sistemato), `value`, `onChange`, `label`.

**Regole:** la sezione attiva ha la pastiglia d'accento al 10 %. Su telefono diventa una fila che scorre.
