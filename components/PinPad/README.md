# PinPad

Tastierino PIN per la cassa condivisa: chi sei, i pallini, tasti tondi da 72 con le cifre in mono.

**Cosa passi:** `length` (4), `value` / `defaultValue`, `onChange`, `onComplete(pin)`, `name`, `text`, `avatar`, `onExit`, `exitLabel`.

**Regole**
- Funziona anche con la tastiera fisica.
- Dopo tre errori: attesa e messaggio, mai il blocco silenzioso.
