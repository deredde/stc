# Wordmark

Il nome del prodotto in carattere display, per i progetti che non hanno ancora un logo; `AppMark` è la tessera con l'iniziale.

**Cosa passi:** `Wordmark`: `name`, `size`. `AppMark`: `letter`, `size` (44 nella barra chiusa · 32 su telefono · 64 per l'icona dell'app).

**Regole:** STC ha il suo logo (l'Esagono, gruppo Logo delle risorse), ma è suo: ogni progetto mette il proprio logo al posto del `Wordmark` (prop `logo` di `Sidebar`, `AuthScreen`, `MemberApp`).
