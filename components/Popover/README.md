# Popover

Pannello ancorato in vetro: la base di tendine, menu e calendari, utile anche per spiegazioni brevi.

**Cosa passi:** `open`, `onClose`, `anchor` (ref dell'elemento), `children`, `placement` (`bottom-start` di serie · `bottom-end` · `top-start` · `top-end` · `right-start`), `width` (numero o `anchor`), `height` (stima, per decidere se aprire sopra), `padding`, `role`, `label`.

**Regole:** si gira sopra se sotto non c'è spazio. Vetro con sfocatura 22 px: abbastanza pieno da leggere. Uno solo aperto alla volta.
