# DocTabs

Più documenti aperti come schede: si fissano, si spostano, si chiudono. Chiede prima di perdere le modifiche.

**Cosa passi:** `tabs`, `max` (di serie 12).

**Quando usarlo**
- App dove si lavora su più documenti insieme: fatture, schede, preventivi.

**Quando no**
- Navigazione tra pagine dell'app: le schede di STC.
- Siti pubblici.

**Regole**
- Al massimo 12 schede; alla tredicesima chiede di chiuderne una.
- Titoli lunghi tagliati a 180 px; il titolo intero nel suggerimento.
- Chiusura: croce, clic centrale o Canc. Le modifiche non salvate chiedono conferma.
- Alt + frecce sposta la scheda.
- Quando non ci stanno, sfumano ai bordi e il menu «Tutte le schede» le elenca.

**Stati coperti:** Attiva · Fissata · Non salvata · Conferma chiusura · Troppe · Vuoto · Focus.
