# Popconfirm

Conferma sul posto, vicino al bottone, per azioni piccole che non si disfano. Vetro come le tendine.

**Cosa passi:** `open`, `onClose`, `anchor` (il ref del bottone), `title`, `text`, `confirmLabel`, `cancelLabel`, `onConfirm`, `placement`, `tone` (`warning` · `danger`).

**Regole**
- Il bottone ripete il verbo: «Togli il promemoria».
- Per eliminare qualcosa che conta usa `ConfirmDialog`.
