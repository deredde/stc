# Switch

Interruttore: accende o spegne una regola che vale subito.

**Cosa passi:** `checked` / `defaultChecked`, `onChange`, `label`, `size` (`md` 36×20 · `sm` 32×18 nei menu), `disabled`.

**Regole:** il pallino scorre in 140 ms. Niente «Salva» dopo un interruttore. Dentro una card con spiegazione usa `SettingRow`.
