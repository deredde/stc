# DayStrip

Striscia dei giorni, il calendario su telefono: sette giorni, oggi in accento, il pallino dove c'è qualcosa.

**Cosa passi:** `days` (`{id, label, day, dot, full}`), `value` / `defaultValue`, `onChange`, `today`, `label`.

**Regole**
- Sotto, la lista del giorno con gli stati di `WeekCalendar`.
- Si scorre di una settimana alla volta.
