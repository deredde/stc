# MobileLargeTitle

Titolo grande su telefono nelle sezioni principali dell'app; allo scroll resta la barra da 52 con il titolo piccolo.

**Cosa passi:** `title`, `subtitle`, `left`, `right` (bottoni icona), `collapsed` (la barra piccola).

**Regole**
- Titolo display 28, una riga di contesto sotto.
- Nelle schede di dettaglio usa `MobileHeader` con la freccia.
