# VerticalTabs

Tab verticali con la barretta d'accento, per dialog larghi e drawer con molte sezioni.

**Cosa passi:** `items` (`{id, label, icon, count}`), `value` / `defaultValue`, `onChange`, `label`.

**Regole**
- Per le pagine di impostazioni resta `SettingsNav`.
- Frecce su e giù per spostarsi.
