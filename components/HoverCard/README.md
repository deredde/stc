# HoverCard

Scheda al passaggio sopra un nome sottolineato a puntini: chi è, due dati, al massimo due azioni.

**Cosa passi:** `children` (il nome), `name`, `subtitle`, `dot`, `details` (le voci di `KeyValue`), `actions`, `delay` (400 ms), `defaultOpen`, `placement`.

**Regole**
- Si apre anche con il fuoco della tastiera.
- Solo informazioni in più: tutto deve essere raggiungibile anche senza.
