# ProgressBar

Barra di avanzamento sottile; `FileProgress` è la riga del file che si carica.

**Cosa passi:** `ProgressBar`: `value` (0–100), `label`, `tone`. `FileProgress`: `name`, `value`, `onCancel`, `icon`.

**Regole:** per durate che si conoscono. Per ciò che non si sa quanto dura usa lo scheletro o la rotella nel bottone.
