# CodeSnippet

Per documentazione e guide per sviluppatori: più linguaggi, copia con conferma, righe evidenziate.

**Cosa passi:** `tabs`, `file`, `theme` (di serie dark), `highlight`, `wrap` (di serie false), `loading`, `maxLines`.

**Quando usarlo**
- Documentazione, guide d'integrazione, chiavi API.

**Quando no**
- Per mostrare un solo valore da copiare: CopyField di STC.

**Regole**
- Scuro di serie anche nel tema chiaro della pagina; la variante chiara solo per file di configurazione.
- Oltre 12 righe si chiude e si apre con «Mostra tutte le righe».
- «Copiato» resta 1,8 secondi e viene letto dai lettori di schermo.
- Righe lunghe scorrono di lato; «Vai a capo» è una scelta della persona.

**Stati coperti:** Riposo · Linguaggio scelto · Copiato · A capo · Chiuso · Aperto · Caricamento.
